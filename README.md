# ComfyUI Kaggle integration — reviewed initial slice

A FastAPI application using a ComfyUI API workflow. Default mock mode requires no GPU.

## Local setup (Windows PowerShell)

```powershell
uv sync
Copy-Item .env.example .env
uv run pytest -v
uv run ruff check .
uv run uvicorn comfy_kaggle_app.main:app --reload
```

Open http://127.0.0.1:8000/docs

`COMFY_MOCK=true` is the default; mock responses have no generated image.

## Kaggle inference

Clone this repo inside Kaggle and run `uv sync`. Start ComfyUI on 127.0.0.1:8188 with the Stable Diffusion 1.5 checkpoint installed. Set `COMFY_MOCK=false` in the environment of the FastAPI process, launch Uvicorn on 127.0.0.1:8000, then POST to `/generate` from the same Kaggle notebook.

The bundled `workflows/text_to_image.json` is a manually constructed **API-format SD1.5 baseline**, not your exported UI workflow. Verify ComfyUI `/prompt` accepts it before changing to larger model families. Node IDs are defined in `workflows/node_map.json` and must match any workflow replacement.

Do not expose either server directly on the public internet. Never commit `.env`, checkpoints, `.venv`, secrets, or generated media. This is a synchronous single-image demonstration, not a production job service.

Note: `uv.lock` must be generated by the developer using `uv lock` or `uv sync` after changing `pyproject.toml`; verification is user-controlled and has not been run here.
